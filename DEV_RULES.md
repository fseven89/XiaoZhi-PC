# ИНЖЕНЕРНЫЙ РЕГЛАМЕНТ И ПРАВИЛА РАЗРАБОТКИ XIAOZHI-PC (JOHNNY)

1. **Виртуальная машина перед прошивкой железа (QEMU-First):**
   - Любые изменения в прошивке `xiaozhi-esp32` сначала собираются и тестируются на виртуальной машине (`simulate_esp32_qemu.ps1` / `build_qemu`).
   - Заливка на физическую колонку по Wi-Fi OTA (`http://192.168.0`) выполняется только после проверки логов ВМ на отсутствие паник ядра и контроль свободной SRAM (> 100 КБ).

2. **Железное правило кодировки (UTF-8 без BOM):**
   - Любая запись файлов из PowerShell или Python выполняется строго в UTF-8 без BOM.

3. **Обязательное сохранение, бэкапы и синхронизация:**
   - Перед изменением рабочих файлов создаётся бэкап в `backups/`.
   - В конце каждого блока работ прогоняется `pytest` и запускается `sync_johnny.ps1` для обновления `workspace/MASTER_CONTEXT.md`.
   - При старте любой новой сессии с ИИ достаточно передать один файл `workspace/MASTER_CONTEXT.md`.

4. **Маршрутизация связи (Telegram Primary + ntfy Fallback):**
   - Основной исходящий канал уведомлений и файлов на Poco F7 — Telegram (через Cloudflare Worker `TELEGRAM_API_BASE`). `ntfy.sh` работает в горячем резерве.
   - Порт `8090` постоянно обслуживается фоновым OTA-сервером внутри `bridge_watchdog.py`.

5. **Ограничения железа ESP32-S3 (`COOLKIT_XZ_02` / `xingzhi-cube-1.54tft-wifi`):**
   - Занятые системные пины (не трогать): `GPIO_NUM_38` (датчик АКБ), `GPIO_NUM_21` (удержание питания), `GPIO_NUM_19/20` (USB/COM6), `GPIO_NUM_26..37` (Octal PSRAM/Flash).
   - Свободные безопасные пины: `1, 2, 3` (ADC1), `11, 12` (UART), `17, 41, 42, 47, 48`.
   - Автоматический Deep Sleep отключён (`PowerSaveTimer(-1, 600, -1)`).

6. **Безопасное выполнение команд через PowerShell 5.1 (без ошибок вставки):**
   - Для патчей и многострочной логики использовать передачу Python-кода в **Base64** (`python -c "import base64; exec(base64.b64decode('...'))"`), чтобы исключить потерю символа `$`, кавычек и переносов строк при вставке в консоль.
   - Файлы `.ps1` с кириллицей сохранять в **UTF-8 с BOM** (`utf-8-sig`), а все остальные файлы (`.py`, `.h`, `.cc`, `.md`, `.json`) — строго в **UTF-8 без BOM**.
   - Не использовать жёсткий путь `$env:USERPROFILE\Desktop` (папка перенесена); сохранять выгрузки в `C:\XiaoZhi-PC` или `[Environment]::GetFolderPath('Desktop')`.
